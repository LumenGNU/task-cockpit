Функция получения задач: битый tasks.json, отсутствующие поля, нечитаемая папка — всё мапится в редуцированный результат, наружу не летит ничего, кроме CancellationError (если поддерживается отмена).

Для любого входа: либо CancellationError, либо WorkspaceState, в котором задач не меньше, чем вернул бы vscode.tasks.fetchTasks на том же снимке. Дальнейшая фильтрация (по label, hide, excludeFolders и т.п.) — только сужает, не теряя того, что VS Code счёл валидным.

То есть тест не «ожидаем 3 задачи из фикстуры», а «ожидаем ≥ того, что вернул VS Code». Эталон генерируется из vscode.tasks.fetchTasks прямо в тесте, фикстура задаёт только сцену, не ответ.
